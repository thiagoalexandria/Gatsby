Os MCP Servers oficiais cobrem muitos casos de uso: aws-api, terraform, pricing, documentacao. Mas e quando voce precisa integrar o Kiro com um sistema interno? Uma API proprietaria, um banco de dados legado, um sistema de tickets? A resposta e criar seu proprio MCP Server. Neste artigo, vamos entender a anatomia do protocolo MCP, desenvolver um servidor customizado e hospeda-lo na AWS de forma segura e escalavel.
